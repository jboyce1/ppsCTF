1. Launch all VMs in CYBER.ORG.

2. Copy the classroom VM inventory from CYBER.ORG; names, labels, and other page text are fine.
   In VS Code, open cyberorg_classroom_targets_dirty.txt, replace everything (Ctrl+A, Ctrl+V), and save (Ctrl+S).

3. In a terminal opened in the local cybercartographer folder, clean the inventory:

python3 cyberorg_classroom_targets_cleaner.py

   Check the saved address count. At "Open GitHub to publish this list? [y/N]", type y and press Enter.
   Press Enter without typing y to keep the cleaned list local instead.

   In VS Code, open cyberorg_classroom_targets.txt, review it, then select all and copy (Ctrl+A, Ctrl+C).
   In the GitHub file editor, select all existing file text and paste (Ctrl+A, Ctrl+V).
   Click Commit changes, then confirm the commit to main in GitHub's dialog.

   If the browser does not open, use:
   https://github.com/jboyce1/ppsCTF/edit/main/workrole/cybercartographer/cyberorg_classroom_targets.txt

   The flagscripts must also be published before running the VM downloads below.

   To download the published list in the range, run:
wget -O cyberorg_classroom_targets.txt https://raw.githubusercontent.com/jboyce1/ppsCTF/main/workrole/cybercartographer/cyberorg_classroom_targets.txt

   COMBINED SETUP OPTION
   On an assigned Ubuntu/Kali VM, download the menu launcher:

wget -O deploy-target.py https://raw.githubusercontent.com/jboyce1/ppsCTF/main/workrole/cybercartographer/challenges/flagscripts/deploy-target.py

   Run it from the VM console:

sudo python3 deploy-target.py

   Enter 136 for SSH 22 + FTP 21 + Telnet 23, or choose other digits from the menu.
   Choose the FTP login mode, confirm with y, and record the final port/flag summary.
   Use existing VM accounts for user logins. Verify access from Kali afterward.
   Installed packages are reused; missing packages show bounded install progress.
   Save the printed report folder: target-summary.txt, diagnostics.txt, and run.log.
   Copy the final inventory block into your notes: VM IP, services, ports, access,
   check results, and flags. The same block is saved as inventory.txt.
   This menu is an alternative to the individual service setup steps below.

   STUDENT-SIDE VALIDATION (on a separate Kali/Ubuntu machine)
   Download the validator:

wget -O validate-target.py https://raw.githubusercontent.com/jboyce1/ppsCTF/main/workrole/cybercartographer/challenges/flagscripts/validate-target.py

   Run it; enter the target IP and an existing VM account/password when prompted:

python3 validate-target.py

   For a comparison against intended services, copy expectations.json from the
   target report folder onto the validation machine using the classroom fileshare.
   Run the comparison:

python3 validate-target.py --expect expectations.json

   If SSH validation reports missing Paramiko, install it on the validation machine:

sudo apt-get install -y python3-paramiko

   Rerun the validator after installing it. Save student-summary.txt from its report
   folder. FAIL means a check failed; INCOMPLETE means checks were skipped, no plan
   was supplied, or an unexpected listener needs review. See README for full TCP scans.

4. Select Ubuntu VMs
    SSH on port 22
    Telnet
    FTP on port 21
    high-port FTP,
    high-port SSH. Use separate VMs for normal and high ports of each service.
    Run the commands for each service on its selected VM, one command at a time.

5. Enable SSH password authentication on the Ubuntu VM for port 22.

sudo sed -i 's/^#\?PasswordAuthentication .*/PasswordAuthentication yes/' /etc/ssh/sshd_config && sudo systemctl restart ssh

6. Set up Telnet on port 23.

wget https://raw.githubusercontent.com/jboyce1/ppsCTF/main/workrole/cybercartographer/challenges/flagscripts/1_deploy-telnet-23.py

sudo python3 1_deploy-telnet-23.py

7. Set up anonymous FTP on port 21.

wget https://raw.githubusercontent.com/jboyce1/ppsCTF/main/workrole/cybercartographer/challenges/flagscripts/4_ftp-anon-login.py

sudo python3 4_ftp-anon-login.py

8. Set up high-port anonymous FTP. Choose one pair of commands.

   With a flag
wget https://raw.githubusercontent.com/jboyce1/ppsCTF/main/workrole/cybercartographer/challenges/flagscripts/2_ftp-anon-highport-flag.py

   Review the configuration at the top of 2_ftp-anon-highport-flag.py before running it.
sudo python3 2_ftp-anon-highport-flag.py

   Without a flag

wget https://raw.githubusercontent.com/jboyce1/ppsCTF/main/workrole/cybercartographer/challenges/flagscripts/3_ftp-anon-highport.py

sudo python3 3_ftp-anon-highport.py

   Record the port printed by the script.

9. Set up high-port SSH. Choose one pair of commands.

   With a flag

wget https://raw.githubusercontent.com/jboyce1/ppsCTF/main/workrole/cybercartographer/challenges/flagscripts/5_ssh-highport-generator-flag.py

   Review the configuration at the top of 5_ssh-highport-generator-flag.py before running it.

sudo python3 5_ssh-highport-generator-flag.py

   Without a flag

wget https://raw.githubusercontent.com/jboyce1/ppsCTF/main/workrole/cybercartographer/challenges/flagscripts/6_ssh-highport-generator.py

   After the download succeeds, run the script.

sudo python3 6_ssh-highport-generator.py

   Record the port printed by the script.

   For password SSH on this VM, also run:
sudo sed -i 's/^#\?PasswordAuthentication .*/PasswordAuthentication yes/' /etc/ssh/sshd_config && sudo systemctl restart ssh

10. Have students download the published target list in Kali.

wget -O cyberorg_classroom_targets.txt https://raw.githubusercontent.com/jboyce1/ppsCTF/main/workrole/cybercartographer/cyberorg_classroom_targets.txt
