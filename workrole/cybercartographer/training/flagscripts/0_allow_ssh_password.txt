On the assigned Ubuntu VM, open the SSH configuration:

sudo nano /etc/ssh/sshd_config

Set PasswordAuthentication yes. Save and exit.
Check that the configuration is valid:

sudo sshd -t

If that succeeds, restart SSH:

sudo systemctl restart ssh

Check effective password authentication (included configuration files may override the main file):

sudo sshd -T

Look for passwordauthentication yes. If it remains no, review the PasswordAuthentication entries in /etc/ssh/sshd_config.d/ and the main file with your instructor. Confirm with the lesson's Nmap authentication scan using the assigned username.
