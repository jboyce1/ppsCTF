RUSTY CURTAIN V2 — QUICK SETUP

Use two clean Ubuntu range VMs per team. Keep the old rustycurtain folder.
Run one command at a time and check its result before the next.
If ppsCTF already exists on a VM, use this instead of the clone command:
sudo git -C ppsCTF pull --ff-only

COMPUTER 1 — Ivan, Tanya, Boris

1. Open a terminal in your home folder. Clone the published challenge files:
sudo git clone https://github.com/jboyce1/ppsCTF.git

2. Enter this challenge folder:
cd ppsCTF/challenges/rustycurtain_v2

3. Check that all five ZIPs match the tested copies. Stop if any line fails:
sha256sum -c ZIP_SHA256SUMS.txt

4. Deploy Computer 1. Set a new LOCAL root password when prompted:
sudo python3 deploy_rustycurtain_1.py

5. Record this VM's range IP.
