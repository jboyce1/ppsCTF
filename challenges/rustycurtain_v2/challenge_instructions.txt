RUSTY CURTAIN V2 — QUICK SETUP

Use TWO CLEAN Ubuntu target VMs. Run these commands on EACH VM.
Keep the repository under /root so students cannot read setup notes.

1. Open a terminal. Become root:
sudo -i

2. Download the challenge:
git clone https://github.com/jboyce1/ppsCTF.git

If /root/ppsCTF already exists, use this command instead:
git -C /root/ppsCTF pull --ff-only

3. Enter the challenge folder:
cd /root/ppsCTF/challenges/rustycurtain_v2

4. Check the ZIPs. All five lines must say OK:
sha256sum -c ZIP_SHA256SUMS.txt
