# Student-facing lessons

- Teach one action at a time. Explain its purpose, give one command when needed, and let students inspect the result before the next action.
- Do not add long scripts, Python one-liners, command chains, pipelines, or multi-command copy-and-paste blocks unless the user explicitly requests them. Do not automate away the skill students are learning.
- Prefer familiar file-manager actions for downloads, creating folders, and opening a terminal in a folder. When terminal navigation is relevant, teach `cd` and `ls` as separate steps.
- Keep commands focused on the tool being taught. Introduce required options briefly; avoid adding alternate workflows, setup machinery, or extra requirements without a teaching need.
- Preserve the teacher's scope and lesson structure. Make targeted changes; do not expand a requested edit into a lesson redesign.
- For CyberCartographer, keep edits local. Do not push or publish changes until the user explicitly approves.
